# Animeko TV 版（旧版）安装包

> **本项目已改名为 Izuko TV**，源代码与新版本都在 [**GrahamZen/izuko-tv**](https://github.com/GrahamZen/izuko-tv)。
> 这个仓库只保存改名之前的 Animeko TV 版安装包，不再发布新功能。

## 旧版怎么升级到 Izuko TV

在旧版里照常检查更新，会先更新到一个过渡版本。过渡版本会引导你安装 Izuko TV，并把设置、登录、数据源与订阅、观看进度与播放记录、缓存都搬过去，搬完提示卸载旧版，之后 Izuko TV 会自动更新到最新版。

也可以直接到 [Izuko TV 的 Releases](https://github.com/GrahamZen/izuko-tv/releases/latest) 下载新版。新版和旧版是两个应用，直接安装不会带上旧版的数据。
